# Clip Pulse

ブラウザー内でローカルに動作する、プライバシー重視のリズム動画エディターです。MP4／MOV の読み込み、動作範囲の選択、タップ、テンプレート、参照音声解析による拍の作成、Rust/WASM、WebCodecs、Mediabunny を使ったリズム適用済み H.264 MP4 の書き出しに対応します。メディアは端末外へ送信されません。

[臺灣正體中文](README.md) · [English](README.en.md) · [ガイド](docs/ja/guide.md)

開発には Node.js 20.19 以上、pnpm 9.15.4、Rust 1.96、wasm-pack が必要です。MVP は最新版デスクトップ Chrome を主対象とします。RxJS はキャンセル可能な音声解析、Zustand は軽量なセッション状態に限定して使用します。素材に音声がある場合、H.264／AAC MP4 の書き出しでは完成動画のクリップ時間軸に合わせて音声を再構成します。参照音声とメトロノームのミキシングは今後の追加機能です。
