# User guide

Open Clip Pulse in current desktop Chrome, choose an MP4/MOV, set the action range, and press Space during playback to tap beats. You can generate a BPM grid or exchange a versioned `.clip-pulse.json` template. Pick a mapping mode and export MP4. Keep the tab open during export; cancellation releases active resources. Processing stays local. Inputs are bounded to 4 GB and ten minutes.
