# User guide

Open Clip Pulse in current desktop Chrome and choose an MP4/MOV. The state-machine workflow guides you through Select action, Set rhythm, then Preview and export. Enter seconds or `minutes:seconds`, or use the current playhead as an In/Out point, and loop-preview the range. Add beats with Space, BPM, a versioned `.clip-pulse.json` template, or reference-audio analysis; individual beats and the full set can be removed. Set the final output duration and mapping mode before exporting MP4. Processing stays local. Inputs are bounded to 4 GB and ten minutes.
