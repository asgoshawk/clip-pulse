# User guide

Open Clip Pulse in current desktop Chrome and choose an MP4/MOV. The state-machine workflow has two steps: Select action, then Compose output. Enter seconds or `minutes:seconds`, or use the source playhead as an In/Out point, and loop-preview the range. Moving In past Out automatically moves Out forward while preserving the range length where possible. In the output timeline, every beat is a clip instance that restarts the selected source range. Set the output duration and add instances with Space, BPM, a versioned `.clip-pulse.json` template, or reference-audio analysis; instances can be moved, removed individually, or cleared. Preview the actual composition before exporting MP4. Processing stays local. Inputs are bounded to 4 GB and ten minutes.
