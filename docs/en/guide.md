# User guide

Open Clip Pulse in current desktop Chrome and choose an MP4/MOV. The state-machine workflow has two steps: Select action, then Compose output. Enter seconds or `minutes:seconds`, or use the source playhead as an In/Out point, and loop-preview the range with immediate mute and volume controls. Moving In past Out automatically moves Out forward while preserving the range length where possible. A three-step onboarding card introduces composition. In the output timeline, every beat is a clip instance that restarts the selected source range. Set the output duration and add instances with Space, BPM, a versioned `.clip-pulse.json` template, or reference-audio analysis; instances can be moved, removed individually, or cleared. The Example link downloads an original 20.5-second cinematic studio-fanfare-style timing template containing no audio; importing it also applies its output duration. Composition preview advances the picture, playhead, and source audio together. When the source has audio, H.264/AAC MP4 export restarts it with each instance, emits silence during held frames, and reverses samples for reverse segments. Preview volume does not change export gain. Processing stays local. Inputs are bounded to 4 GB and ten minutes.
