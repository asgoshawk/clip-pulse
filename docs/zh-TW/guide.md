# 使用指南

1. 使用最新版桌面版 Chrome 開啟 Clip Pulse，選擇 MP4 或 MOV。
2. 在「選取動作」輸入秒數或 `分:秒`，也可拖動播放位置後按「目前位置設為起點／終點」。若起點超過終點，終點會自動往後移動並保留原本片段長度。使用循環預覽確認要重複的來源片段；播放列可即時調整音量或靜音。
3. 按「使用這段動作」進入「編排成品」，並依畫面上的三步操作引導開始。成品時間軸上的每個拍點都是一個片段實例：播放到該位置時，會從頭播放一次步驟一選取的來源片段。
4. 設定成品總長度，再以成品播放位置與 Space、新增按鈕、BPM、版本化 `.clip-pulse.json` 範本或參考音訊分析建立片段實例。每個實例都可移動或刪除，也可清除全部；成品預覽會依時間軸實際播放。
5. 按播放鍵可即時確認畫面、播放頭與來源聲音，再按「匯出 MP4」。預覽音量不影響來源檔案；匯出的 MP4 目前仍不含音訊。匯出期間請保持分頁開啟；可隨時取消以釋放資源。

所有媒體均在本機處理。請勿匯入不信任的超大型檔案；應用程式會限制為 4 GB 與 10 分鐘。
