# 使用指南

1. 使用最新版桌面版 Chrome 開啟 Clip Pulse，選擇 MP4 或 MOV。
2. 在「選取動作」輸入秒數或 `分:秒`，也可拖動播放位置後按「目前位置設為起點／終點」。使用循環預覽確認片段。
3. 進入「設定節奏」，播放時按 Space 即時加入拍點、用 BPM 建立拍點，或上傳參考音訊進行本機分析。每個拍點都可單獨刪除，也可清除全部。
4. 進入「預覽匯出」，設定成品總長度與重播、填滿、停格或來回對應，再播放節奏預覽。
5. 按「匯出 MP4」。匯出會套用節奏映射，但目前不含音訊。匯出期間請保持分頁開啟；可隨時取消以釋放資源。

所有媒體均在本機處理。請勿匯入不信任的超大型檔案；應用程式會限制為 4 GB 與 10 分鐘。
