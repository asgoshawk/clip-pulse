# ユーザーガイド

最新版デスクトップ Chrome で Clip Pulse を開き、MP4／MOV を選択します。ステートマシンは「動作選択」と「完成動画の構成」の 2 段階です。秒または `分:秒` を入力するか、素材の再生位置を開始／終了点に設定し、音量を調整しながら範囲をループ確認できます。開始点が終了点を越えると、可能な限り範囲の長さを保ったまま終了点が後方へ移動します。完成動画の構成では、最初に 3 段階の操作ガイドが表示されます。タイムラインの各拍は、選択範囲を先頭から再生するクリップ実体です。完成尺を設定し、Space、BPM、バージョン付き `.clip-pulse.json`、参照音声解析でクリップ実体を追加してください。個別に移動／削除することも、すべて消去することもできます。「範例」リンクから、音声を含まないオリジナルの約 20.5 秒の映画会社ファンファーレ風タイミング例を取得でき、読み込むと完成尺も自動設定されます。プレビューでは映像、再生位置、素材音声が一緒に進みます。書き出した MP4 にはまだ音声が含まれません。処理はすべてローカルで行われます。
